# Virtual Interview Simulator

A frontend-only student project using HTML, CSS and JavaScript.

## Team division
- Member 1: UI/Frontend — HTML, CSS, responsive design
- Member 2: Interview Logic — question bank, randomization, timer, navigation
- Member 3: Recording & Scoring — Web Speech API, keyword scoring, results

## Run
Open `index.html` in a modern browser. No backend is required.

## Important
Voice recognition depends on browser support and microphone permission. Text input is provided as a fallback.

## GitHub Pages
Upload the project to a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from branch → main → root.
